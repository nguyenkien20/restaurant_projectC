# Restaurant Management System (C Project)

This repository contains a restaurant management system written in C. It's a project built after about three months of learning the language, applying core programming concepts to a practical use case.

## Key Concepts Used

- **Finite State Machine (FSM):** Uses `enum` and `switch-case` to manage system states such as Main Menu, Table Selection, Ordering, Bill Generation, and Admin Settings.
- **Data Structures:** Uses `struct` and arrays to organize menu items, customer orders, and table statuses.
- **File I/O:** Reads and writes text files to persist menu data and daily revenue.
- **Pointers:** Uses pointers for pass-by-reference, direct memory access, and pointer arithmetic.
- **Control Flow & Logic:** Code is split into modular functions for readability and maintainability.
